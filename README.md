# Campus Auction

Campus Auction is a modern auction platform for Noroff students where users can create listings, place bids, and manage their profiles.

The project was built using TypeScript, Vite, Tailwind CSS, and the Noroff Auction API.

---

# Live Site

[Open Application] https://campus-auction.netlify.app/

---

# Features

## Authentication

- Register with `@stud.noroff.no` email
- Login and logout
- Protected authenticated pages
- Persistent login using local storage

## Listings

- Browse all listings
- Search listings by title and description
- Filter listings by tags/categories
- Sort listings by newest or ending soon
- Responsive listing cards
- Listing details page

## User Actions

- Create listings
- Edit listings
- Delete listings
- Place bids on listings
- View bid history
- Prevent bidding on own listings

## Profile

- View user profile
- Edit avatar
- Edit banner
- Edit bio
- View credits
- View listings and wins

## UI / UX

- Responsive design
- Semantic Tailwind color system
- Loading spinners
- Toast notifications
- Shared reusable navbar
- Modern card-based layouts
- Accessible form labels and semantic HTML

# Installation

## Clone repository

```bash
git clone https://github.com/ebbestankiewicz/campus-auction.git
```

## Install dependencies

```bash
npm install
```

## Run development server

```bash
npm run dev
```

## Build project

```bash
npm run build
```
